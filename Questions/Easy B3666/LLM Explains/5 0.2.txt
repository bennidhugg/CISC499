## Algorithm Description

### [1] Problem Summary

The problem requires finding the suffix maximum values' indices in a dynamically growing sequence and calculating their bitwise XOR after each insertion.

### [2] Formal Problem Definition

Given a sequence $a$ that is initially empty, we need to process $n$ operations where each operation adds a positive integer $x$ to the end of $a$. After each operation, we must find all suffix maximum values' indices in the current sequence $a$ and calculate their bitwise XOR.

### [3] Input Specification

- The first line contains an integer $n$, representing the number of operations.
- The second line contains $n$ integers, each representing a value $x_i$ to be added to the sequence $a$.

### [4] Output Specification

After each operation, output a single integer representing the bitwise XOR of all suffix maximum values' indices in the current sequence $a$.

### [5] Constraints

- $1 \leq n \leq 10^6$
- $1 \leq x_i < 2^{64}$

### [6] Key Observations

- The problem can be solved by maintaining a data structure that allows efficient insertion and querying of suffix maximum values.
- The bitwise XOR operation has the property that $a \oplus a = 0$ and $a \oplus 0 = a$, which can be utilized to update the XOR result efficiently.

### [7] Algorithm Idea

- We will use a stack-based approach to keep track of the suffix maximum values' indices.
- The stack will store indices of the elements in the sequence $a$.
- For each new element added to $a$, we will pop elements from the stack that are smaller than the new element and update the XOR result accordingly.

### [8] Detailed Algorithm Steps

1. Initialize an empty stack and an empty sequence $a$.
2. Read the number of operations $n$ and the values $x_i$ to be added to $a$.
3. For each operation:
   1. Add the new element $x_i$ to the end of sequence $a$.
   2. Initialize a variable to store the XOR result.
   3. Pop elements from the stack that are smaller than $x_i$ and update the XOR result.
   4. Push the index of $x_i$ onto the stack.
   5. Calculate the new XOR result including the index of $x_i$.
4. Output the XOR result after each operation.

Note: The algorithm utilizes a stack to efficiently manage the suffix maximum values' indices and calculates the bitwise XOR after each insertion.
