## Algorithm Description

### [1] Problem Summary

The problem requires finding the suffix maximum values' indices in a dynamically growing sequence and calculating their bitwise XOR after each insertion.

### [2] Formal Problem Definition

Given a sequence $a$ that is initially empty, we need to process $n$ insertions of positive integers $x_i$. After each insertion, we must find all suffix maximum values' indices in the current sequence $a$ and calculate their bitwise XOR.

### [3] Input Specification

- The first line contains an integer $n$, representing the number of insertions.
- The second line contains $n$ integers $x_i$, representing the values to be inserted.

### [4] Output Specification

After each insertion, output the bitwise XOR of the indices of all suffix maximum values in the current sequence.

### [5] Constraints

- $1 \leq n \leq 10^6$
- $1 \leq x_i < 2^{64}$

### [6] Key Observations

- The problem can be solved by maintaining a data structure that allows efficient insertion and querying of suffix maximum values.
- The bitwise XOR operation can be used to combine the indices of suffix maximum values.

### [7] Algorithm Idea

- Use a stack to keep track of the indices of the suffix maximum values.
- When a new element is inserted, pop elements from the stack that are smaller than the new element and update the stack.
- Calculate the bitwise XOR of the indices in the stack.

### [8] Detailed Algorithm Steps

1. Initialize an empty stack to store indices of suffix maximum values.
2. Read the number of insertions $n$ and the values $x_i$.
3. For each insertion:
   - While the stack is not empty and the top element is smaller than $x_i$, pop the stack.
   - Push the current index onto the stack.
   - Calculate the bitwise XOR of the indices in the stack.
   - Output the XOR result.
4. Repeat step 3 for all insertions.

## Implementation Details

- The stack will store indices of suffix maximum values.
- The bitwise XOR operation will be used to combine indices.
- The algorithm will iterate over the insertions, updating the stack and calculating the XOR result after each insertion.

The output will be the XOR results after each insertion.
