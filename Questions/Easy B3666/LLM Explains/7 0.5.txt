## Algorithm Description

### [1] Problem Summary
The problem requires finding the suffix maximum values' indices in a dynamically growing sequence and calculating their bitwise XOR after each insertion.

### [2] Formal Problem Definition
Given a sequence $a$ that is initially empty, we need to process $n$ insertions of positive integers $x$. After each insertion, we must find all suffix maximum values' indices in the current sequence $a$ and calculate their bitwise XOR.

### [3] Input Specification
- The first line contains an integer $n$, representing the number of insertions.
- The second line contains $n$ integers $x_i$, representing the values to be inserted.

### [4] Output Specification
After each insertion, output the bitwise XOR of the indices of all suffix maximum values in the current sequence.

### [5] Constraints
- $1 \leq n \leq 10^6$
- $1 \leq x_i < 2^{64}$

### [6] Key Observations
- The problem can be solved by maintaining a data structure that allows efficient insertion and querying of suffix maximum values.
- The bitwise XOR of indices can be calculated by iterating over the suffix maximum values' indices and performing XOR operations.

### [7] Algorithm Idea
- Use a stack or a similar data structure to keep track of the suffix maximum values' indices.
- After each insertion, update the stack to reflect the new suffix maximum values.
- Calculate the bitwise XOR of the indices in the stack.

### [8] Detailed Algorithm Steps
1. Initialize an empty stack to store the indices of suffix maximum values.
2. For each insertion of a new value $x$:
   1. While the stack is not empty and the top value is less than $x$, pop the stack.
   2. Push the current index onto the stack.
   3. Calculate the bitwise XOR of the indices in the stack.
3. Output the bitwise XOR after each insertion.

## Implementation Details
- The algorithm iterates over the insertions, maintaining a stack of indices of suffix maximum values.
- The stack is updated after each insertion by popping elements that are no longer suffix maximum values and pushing the current index.
- The bitwise XOR of the indices in the stack is calculated after each update.

The final output is the sequence of XOR results after each insertion.
